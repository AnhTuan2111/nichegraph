# Decisions

An ADR records a decision that has been accepted and whose implementation has started. ADRs are append-only: a later
ADR supersedes an earlier one, and each links to the other.

A file is named `YYYY-MM-DD-<what-was-decided>.md` and holds: status, date and decision owner; context; decision;
alternatives considered, with the reference each is learned from; consequences.
